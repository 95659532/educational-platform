# educational-platform

منصة تعليمية احترافية تم تصميمها كـ MVP جاهز للعرض والتطوير. المشروع يتضمن صفحات رئيسية، قائمة دورات، صفحة تسجيل دخول، ولوحة تحكم للطلاب.

## المميزات

- صفحة رئيسية احترافية للمنصة التعليمية
- قسم الدورات مع بطاقات دورات جذابة
- قسم الإحصائيات ومزايا المنصة
- قسم التقييمات وآراء المستخدمين
- صفحة تسجيل دخول/إنشاء حساب
- صفحة لوحة تحكم للطالب
- تصميم متجاوب باللغة العربية
- دعم Tailwind CSS و Next.js

## التقنيات المستخدمة

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح المتصفح على:

```bash
http://localhost:3000
```

## هيكل المشروع

- `app/` : الصفحات الرئيسية للتطبيق
- `components/` : مكونات واجهة المستخدم
- `data/` : بيانات تجريبية للمنصة
- `app/globals.css` : أنماط المشروع

## المشاريع المستقبلية

- إضافة لوحة تحكم للإدارة
- نظام اشتراكات ودفع
- إدارة المحتوى من قبل المدرسين
- اختبارات وواجبات
- فيديوهات ومحتوى تعليمي متقدم
